# Frameworks_Assignment – CORD-19 Data Explorer

## 📌 Overview
This project analyzes the CORD-19 dataset (`metadata.csv`) and presents findings through:
- A Jupyter Notebook for analysis
- A Streamlit app for interactive visualization

## 🎯 Objectives
- Load and explore a real-world dataset
- Clean data (missing values, date parsing, derived columns)
- Perform simple analyses (publication trends, top journals, word frequencies)
- Create meaningful visualizations
- Build an interactive Streamlit app
